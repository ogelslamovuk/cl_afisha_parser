# Agents

## Роль Codex в этом проекте

Codex должен реализовывать только явно поставленные задачи по проекту `cl_afisha_parser`.

## Рабочие правила

1. Не менять архитектуру без явного запроса.
2. Не добавлять SQL, базы данных, веб-фронт, Docker, CI/CD или внешнюю публикацию в первой итерации.
3. Первая итерация — локальный Python-проект, запускаемый из PyCharm через `main.py`.
4. Основной выходной файл должен повторять структуру эталонного `go2.json`.
5. Скрипт не должен выполнять покупку билетов, авторизацию, обход капчи или платёжные действия.
6. Источник первой итерации — публичные страницы Bycard, где расписание доступно в `window.__NUXT__`.
7. Перед кодингом Codex должен кратко объяснить, какие файлы создаст и как будет реализовывать задачу.
8. Код писать только после явного подтверждения пользователя.

## Ограничения первой итерации

Разрешено:
- Python;
- Playwright;
- YAML-конфиг;
- локальная запись JSON;
- локальный архив успешных выгрузок;
- простой консольный лог.

Запрещено в первой итерации:
- SQL/SQLite/PostgreSQL;
- web API/server;
- frontend;
- GitHub publication output;
- Telegram notifications;
- complex snapshot diffing.
