# CL Afisha Parser

Локальный Python-парсер расписания Bycard/24afisha для выгрузки афиши в JSON-формате, совместимом по структуре с текущим `go2.json`.

## Итерация 1

Цель: локальный MVP, запускаемый из PyCharm через `main.py`.

Результат запуска:

- `output/current/go2.json` — основной JSON в структуре, совместимой с эталонным `go2.json`;
- `output/current/report.json` — технический отчёт запуска;
- `output/archive/` — архивные копии успешных выгрузок.

Публикация наружу, сравнение JSON и Telegram-уведомления — следующие итерации.
